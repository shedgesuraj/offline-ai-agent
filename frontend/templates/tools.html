Tools & Safety

File tool

Workspace-only list/read/write operations, bounded reads/writes, and audit events.

Python tool

AST validation, safe-module allowlist, blocked dangerous calls/attributes, isolated Python mode, resource limits, output capture and timeout. Risky execution requires approval by default.

Terminal tool

Allowlisted commands only, workspace path checks, no shell chaining/redirection, resource limits and timeout. Risky execution requires approval by default.

Verification

Successful subprocess exit codes are required before a task is marked verified. Failed Python can request a bounded local-model repair attempt.

Sandbox boundary

Agent subprocesses run in the workspace with resource/process limits and forced cleanup. This is defense-in-depth, not a hostile-code VM.

Privacy

Chat history is off by default. Only explicit memories and explicitly indexed documents persist.
